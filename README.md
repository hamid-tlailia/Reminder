# وِردي 🌿 — أذكاري ووِردي اليومي

تطبيق أذكار عصري (ويب + قابل للتثبيت كتطبيق PWA) يعالج مشكلة واحدة أساسية:
**«أين وصلت؟»** — فلا يضيع عليك عدّ ولا مكان.

## المزايا

| الميزة | الوصف |
| --- | --- |
| **عدّاد لكل ذكر** | اضغط الزر الكبير للعدّ، واضغط مطوّلًا (نصف ثانية) للرجوع خطوة. لا يتجاوز العدّاد العدد المطلوب أبدًا. |
| **حفظ مكانك في الجولات** | الأذكار الطويلة (أذكار الصباح/المساء، جولة الاستغفار، تسبيح دبر الصلاة، تسبيح النوم) تُقدَّم كـ «جولة» خطوة بخطوة، ويُحفظ رقم الخطوة والعدّ داخلها، فتستأنف من حيث توقفت بالضبط حتى بعد إغلاق التطبيق. |
| **تقسيم حسب الزمان** | صباح / مساء / يوم — مع فصل كامل للأعداد: ما عدّدته صباحًا لا يُحسب على المساء. التبديل تلقائي حسب الساعة، أو يدوي. |
| **وسم «اكتمل»** | زر ✓ في نافذة التفاصيل يوسم الذكر كاملًا دون عدّ (إن أكملته خارج التطبيق). |
| **الفوائد والمصادر** | لكل ذكر: فضله وفائدته، ومصدره (البخاري، مسلم، السنن، حصن المسلم…). |
| **المسبحة** | عدّاد بحلقة تقدّم، أذكار جاهزة قابلة للتغيير، أهداف (٣٣ / ١٠٠ / ٥٠٠ / مخصص)، إحصاء يومي وإجمالي. |
| **وِرد القرآن** | متابع صفحات (صفحتان يوميًا افتراضيًا) مع **حفظ رقم الصفحة وموضع الآية**، قارئ للصفحة بالنص العثماني، انتقال للأجزاء وبحث عن السور، وسجل أسابيع. |
| **تقدّمي** | سلسلة الأيام المتتالية، نسب الإنجاز، خريطة التزام ١٢ أسبوعًا، أوسمة، سجل آخر الأيام. |
| **ثيم فاتح/داكن** | ثلاث حالات: داكن، فاتح، تلقائي حسب ساعة اليوم. مع تحكّم بحجم الخط والتشكيل وتقليل الحركة. |
| **يعمل بدون إنترنت** | عامل خدمة (Service Worker) يخزّن التطبيق؛ ويُخزَّن نص القرآن بعد أول تحميل. كل بياناتك في جهازك، بلا حساب ولا سيرفر. |
| **تصدير/استيراد** | نسخة JSON من كل بياناتك للاحتفاظ أو الانتقال بين الأجهزة. |

## التشغيل

```bash
npm start          # يشغّل الموقع على http://localhost:4173
npm test           # اختبار دخان شامل لكل المسارات والعمليات
npm run icons      # إعادة توليد أيقونات التطبيق
```

لا تبعيات إطلاقًا: المشروع HTML + CSS + JavaScript بمعيار ES Modules، وخادم التطوير بـ Node خالص.

## التثبيت كتطبيق 📱

**أندرويد (كروم):** القائمة ⋮ ← «تثبيت التطبيق».
**آيفون (سفاري):** زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».
**سطح المكتب (كروم/إيدج):** أيقونة التثبيت في شريط العنوان.

يظهر التطبيق بأيقونته الخاصة **وِردي**، بلا شريط متصفح، ويعمل في وضع مستقل.

## الأيقونة

مسبحة ذهبية من ١٢ خرزة + نجمة إسلامية ثمانية + جوهرة مركزية، على خلفية زمردية متدرّجة بنقش هندسي.
تُولَّد برمجيًا بلا أي مكتبات (Signed Distance Fields + كاتب PNG داخلي):

```
node tools/make_icons.mjs
```

تُنتج `assets/icons/`: مقاسات ٢٤/٣٢/٤٨/١٤٤/١٨٠/١٩٢/٥١٢/١٠٢٤، وأيقونة maskable، و`favicon.ico`، وصورة مشاركة ١٢٠٠×٦٣٠.

## بنية المشروع

```
index.html                  هيكل التطبيق + شاشة البدء
manifest.webmanifest        بيانات التطبيق (PWA) والاختصارات
sw.js                       عامل الخدمة: العمل بدون إنترنت
assets/icons/               كل الأيقونات (مولّدة)
src/
  app.js                    التهيئة: الهيكل، التنقّل، الثيم، التنبيهات، التثبيت
  store.js                  الحالة + الحفظ التلقائي + الإحصاءات (localStorage)
  data/adhkar.js            مكتبة الأذكار: النصوص، الأعداد، الأوقات، الفوائد، المصادر
  ui/dom.js                 أدوات العناصر، الأيقونات، الأوراق السفلية، التنبيهات، الاحتفال
  ui/widgets.js             حلقة التقدّم، بطاقة الذكر، جولة الأذكار، لوحة التفاصيل
  views/                    today · library · tasbeeh · quran · stats · settings
  styles/main.css           نظام التصميم (داكن/فاتح، مكوّنات، حركات)
tools/
  server.mjs                خادم تطوير ثابت
  make_icons.mjs            مولّد الأيقونات
  smoke.mjs                 اختبار الدخان (بلا متصفح)
```

## الورد الافتراضي

عند أول تشغيل يُهيّأ «وِردك» على:

1. **الباقيات الصالحات** — «لا إله إلا الله وحده لا شريك له…» × ١٠٠
2. **سبحان الله وبحمده** × ١٠٠
3. **جولة الاستغفار** — ١٠٠ استغفار ← ٧ «ربي اغفر لي وارحمني…» ← ٧ «لي ولوالدي وللمؤمنين» ← ٧ «خطيئتي يوم الدين» ← ٣ «الحي القيوم» ← ٣ «العظيم» ← سيد الاستغفار
4. **الصلاة على النبي ﷺ** — ١٠ صباحًا و١٠ مساءً
5. **أذكار الصباح** و**أذكار المساء** — جولتان متتابعتان
6. **وِرد القرآن** — صفحتان يوميًا (صباحًا أو مساءً)

ويمكنك إضافة/إزالة أي ذكر، أو إنشاء أذكارك الخاصة بعدد تحدّده أنت.

## ملاحظات

- النص القرآني يُجلب برسم عثماني من `api.alquran.cloud` (يُخزَّن بعد أول تحميل). الأذكار النبوية مضمَّنة داخل التطبيق فتعمل دائمًا بدون إنترنت.
- الأذكار والفوائد من صحيح البخاري ومسلم والسنن وكتاب «حصن المسلم»؛ يُنصح بمراجعة أهل العلم في الأعداد والفوائد.
- إشعارات الويب تذكّر بأذكار الصباح والمساء ما دام المتصفح يعمل؛ على الأنظمة التي تُوقف التطبيق تمامًا في الخلفية يعتمد التذكير على فتح التطبيق.
